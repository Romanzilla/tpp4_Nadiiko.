- `bin/StatAnalysis.dll` — скомпільована динамічна бібліотека.

## Специфікація API та граничних умов

### 1. `double mean(const double* data, int n)`
- **Призначення:** обчислює середнє арифметичне елементів вибірки.
- **Вхідні параметри:** `data` — вказівник на масив `double` (не змінюється); `n` — кількість елементів (`n >= 1`).
- **Результат:** середнє арифметичне.
- **Граничні умови та помилки:** якщо `data == nullptr`, `n <= 0` або масив містить `NaN`/`Inf`, повертає `NAN`.

### 2. `double variance(const double* data, int n, int isSample)`
- **Призначення:** обчислює дисперсію вибірки (`isSample != 0` — незміщена вибіркова зі знаменником `n - 1`; `isSample == 0` — генеральна зі знаменником `n`).
- **Граничні умови та помилки:** при `data == nullptr`, `n < 2` (для вибіркової) або `n < 1` (для генеральної) повертає `NAN`.

### 3. `double stdDev(const double* data, int n, int isSample)`
- **Призначення:** обчислює стандартне відхилення $\sqrt{\text{variance}}$.
- **Граничні умови та помилки:** аналогічні до `variance()` (повертає `NAN` при некоректних параметрах).

### 4. `double median(const double* data, int n)`
- **Призначення:** обчислює медіану (50-й перцентиль) без модифікації вхідного масиву (використовується внутрішня копія).
- **Граничні умови та помилки:** при `data == nullptr` або `n <= 0` повертає `NAN`.

### 5. `int quartiles(const double* data, int n, double* q1, double* q2, double* q3)`
- **Призначення:** обчислює перший (`Q1`, 25%), другий (`Q2`, 50%) та третій (`Q3`, 75%) квартилі.
- **Результат:** `0` при успішному обчисленні; `-1` при помилці (`data == nullptr`, `n <= 0`, або будь-який із вказівників `q1`, `q2`, `q3` дорівнює `nullptr`).
